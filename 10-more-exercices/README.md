# Bootstrap 5 Exercises
 
Practice exercises covering the main Bootstrap 5 components and utilities.
 
## Exercises
 
### Task 1 - Display Heading
Created a larger heading using Bootstrap display classes.
 
### Task 2 - Styled Table
Created a table with hover effects and contextual row colors.
 
### Task 3 - Buttons
Created:
- Outline danger button
- Small disabled success button
- Large warning button acting as a link
 
### Task 4 - List Group
Created a list group containing three elements.
 
### Task 5 - Dropdown
Created a dropdown menu with four links and a separator.
 
### Task 6 - Nav Pills
Created a pills navigation menu with two links.
 
### Task 7 - Carousel
Built a Bootstrap carousel containing two images with automatic sliding.
 
### Task 8 - Responsive Grid
Created a responsive grid:
- 1 column on small screens
- 2 columns on small devices and above
- 4 columns on medium devices and above
 
### Task 9 - Toast Notification
Created a toast notification activated through a button click.
 
### Task 10 - Figure
Created a responsive figure with:
- Thumbnail image
- Responsive sizing
- Caption positioned below the image

Completed 10 Bootstrap 5 exercises demonstrating responsive layouts, interactive components, styling utilities, and JavaScript integration.
