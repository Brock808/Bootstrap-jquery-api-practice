# Bootstrap & jQuery Practice
 
This repository contains three small exercises built with Bootstrap 5, Bootstrap Icons, jQuery and API
 
## Exercise 1: Bootstrap Components
 
Features:
 
- Paragraphs styled using Bootstrap heading classes (`h1`, `h2`, `h3`)
- Interactive List Group
- Figure component with image and caption
- jQuery event handling for list items
 
Technologies used:
 
- Bootstrap 5
- Bootstrap Icons
- jQuery
 
---
 
## Exercise 2: Navbar, Toast & Carousel
 
Features:
 
- Responsive navbar with four Bootstrap Icons
- Toast notification triggered by clicking an icon
- Bootstrap carousel with two images
- Carousel navigation controls
- Three-button group with different Bootstrap colors
 
Technologies used:
 
- Bootstrap 5
- Bootstrap Icons
- jQuery
 
---
 
## Exercise 3: API Request with AJAX
 
Features:
 
- AJAX request using jQuery
- Data retrieval from GitHub API
- Console logging of API response
- Basic asynchronous JavaScript handling
 
Technologies used:
 
- Bootstrap 5
- jQuery
- GitHub REST API
 
---
 
## Skills Practiced
 
- Bootstrap layout and utility classes
- Bootstrap components
- Navbar
- Toast
- Carousel
- Button Groups
- List Groups
- Figures
- Bootstrap Icons
- DOM manipulation with jQuery
- Event handling
- AJAX requests
- Working with external APIs
